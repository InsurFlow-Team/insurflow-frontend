# Screenshots

Place real product screenshots in this folder. The landing page expects these files:

| File | Description | Used In |
|------|-------------|---------|
| `dashboard.png` | Main dashboard overview | Hero |
| `mobile.png` | Mobile app — assignment/inspection | Hero |
| `claims-dashboard.png` | Claims list page | Claims Officer |
| `dispatch-map.png` | Dispatch map with pins | Dispatch |
| `policy-verification.png` | Policy verification form | Policy Verification |
| `mobile-assignment.png` | Mobile — new claim/accept/decline | Field Adjuster |
| `mobile-inspection.png` | Mobile — inspection form | Field Adjuster |
| `mobile-evidence.png` | Mobile — evidence/signature | Field Adjuster |
| `gallery-dashboard.png` | Dashboard (gallery) | Product Gallery |
| `gallery-map.png` | Map (gallery) | Product Gallery |
| `gallery-details.png` | Claim details (gallery) | Product Gallery |
| `gallery-mobile.png` | Mobile inspection (gallery) | Product Gallery |

## How to capture

1. Run the dashboard: `npm run dev`
2. Sign in with demo credentials
3. Navigate to each page and take a screenshot (browser dev tools → screenshot)
4. Save the image with the exact filename listed above
5. For mobile screenshots, use the mobile app or browser dev tools device toolbar

## Tips

- Use 1280×720 or 1920×1080 for desktop screenshots
- Use 375×812 (iPhone) or 360×800 (Android) for mobile screenshots
- PNG format recommended for clarity
- Make sure the UI is in a realistic state (some data visible)
